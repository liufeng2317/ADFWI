ADFWI Homepage
==============

Welcome to the **ADFWI** homepage! This repository provides an advanced framework for **Automatic Differentiation-Based Full Waveform Inversion**. Below are the main sections of the documentation:

.. toctree::
   :maxdepth: 2
   :caption: ADFWI Documentation

   readme
   Tutorial/tutorial
   Examples/examples
   API/ADFWI

Explore the resources below to get started:

- **README**: An introduction to ADFWI, installation instructions, and basic usage.
- **Tutorials**: Step-by-step guides on ADFWI's core functionalities, basic principles, and dependencies, helping users understand the underlying principles of acoustic and elastic FWI models and how to apply them.
- **Examples**: Practical examples covering various case studies of acoustic and elastic inversion.
- **API Reference**: A detailed guide to the ADFWI functions and classes.
